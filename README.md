# Compact GitHub Pages Portfolio

This is a build-free static website. Upload everything in the `outputs` folder to the root of your GitHub Pages repository to publish it.

## Publish with GitHub Pages

1. Create a public GitHub repository named `username.github.io`, replacing `username` with your GitHub username.
2. Upload every file in this folder to the repository root and push to the default branch.
3. Open **Settings → Pages**, then select the deployment branch and `/ (root)`.
4. Your page will appear at `https://username.github.io` after GitHub finishes publishing it.

For a project repository, the address is usually `https://username.github.io/repository-name/`. All local assets use relative paths, so the page works in either setup.

## Replace These Placeholders

Edit `index.html` and replace every matching placeholder with your real information.

| Placeholder | Replace with |
| --- | --- |
| `[Name]` | Your display name |
| `[N]` | Your initial or short monogram |
| `[Role]` | Your role, such as Product Designer or Front-end Developer |
| `[School / Organization]` | Your school, company, team, or independent status |
| `[Email]` | Your email address |
| `[City / Remote]` | Your location or remote availability |
| `[Area of Interest]` | The problems or field you focus on |
| `[School / Program]` | Your school or learning program |
| `[Major or Field of Study]` | Your major or area of study |
| `[Interest 01]`–`[Interest 03]` | Topics you are exploring now |

The projects/publications and awards/activities sections are intentionally empty until there is factual content to add. The template contains no invented achievements, metrics, or active social links.

## Files

- `index.html` — page content and metadata
- `styles.css` — responsive layout and visual design
- `script.js` — automatic copyright year
- `404.html` — page-not-found screen
- `.nojekyll` — tells GitHub Pages to serve the static files directly

No installation or image files are required.
